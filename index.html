AI 분석 · 원문 근거 비교

규칙 기반 값은 유지한 채 AI 제안을 별도로 분석하고 항목별로 확인합니다.

모의 비교는 동봉된 sample_application.txt로만 작동하며 실제 AI를 호출하지 않습니다. 외부 AI는 배포본에 포함된 해시 검증 합성 TXT만 사용할 수 있습니다. 실제 민원 원본 및 개인정보 자료는 외부 AI로 전송할 수 없습니다. AI 분석 시 신청서의 추출 텍스트 일부가 연결된 모델로 전송됩니다. AI가 제안한 값은 자동 반영되지 않습니다.

API 키 없이도 동봉된 sample_application.txt를 업로드하고 ‘모의 비교 체험’을 선택하면 비교표를 시험할 수 있습니다. 모의 결과는 실제 AI 성능이 아닙니다.

추출 정확도 평가 · 합성 시험자료

사건 데이터는 변경하지 않습니다. 정답이 있는 가상 신청서 4건 / 16개 필드 기준

규칙 평가는 오프라인으로 실행됩니다. 실제 AI 평가는 모델 연결과 명시적 동의가 필요하며, 내장 합성자료만 전송합니다. 결과는 실제 세움터 서식의 정확도 보증이 아닙니다.
